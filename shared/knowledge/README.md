# Knowledge Storage Rules

Record id, scope (common/project/task), project_id, claim_kind (fact/hypothesis/decision), statement, sources, observed_at, review_after, and supersedes in index.json entries. Sources must be accessible file paths or URLs. Check dates and applicability before reuse. Keep working hypotheses and unevaluated experimental results in the relevant runs/ directory. Write agent-facing knowledge in English and user-facing reports in Korean; never store credentials or unnecessary private data.

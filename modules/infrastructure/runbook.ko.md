# 인프라 변경 런북 양식

| 기록할 항목 | 작성 내용 |
|---|---|
| 사전 점검 | 작업 ID, 서비스·환경 가명, 승인된 범위와 실행자, 유지보수 시간, 현재 버전·상태, 사용자 정상 연결 기준선, 백업 시각 및 복구 경로를 기록한다. |
| 영향 범위 | 변경 대상과 의존 서비스, 인증·라우팅·감사 로그 영향, 예상 중단 시간과 변경 중지 조건을 적는다. |
| 적용 | 검토한 후보와 승인된 효과를 확인한다. 계획 결과, 파일럿 대상, 적용 시각과 실제 실행 결과를 각각 기록한다. |
| 검증 | 서비스 상태, 기존 인증 유지, 대표 클라이언트의 재접속, 감사 이벤트의 수집·종료 기록을 기준선과 대조한다. 미실행은 not_run으로 남긴다. |
| 롤백 | 발동 조건, 실행자, 정상 버전과 같은 시점의 설정, 대체 관리 경로를 지정한다. 실패 기간의 증거는 민감 값을 제외하고 보존한다. 복원 뒤 인증·헬스·감사 로그를 다시 확인한다. |

원격 경로가 변경 대상이면 기존 접속을 유지하고 별도 관리 경로와 새 접속 성공을 확인한다. 대상 계정과 주소는 가명으로 기입한다. 본문과 증거 파일에 비밀번호·키를 남기지 않는다.

기존 SoftEther 작업의 정상 접속 기준선 → 복구 준비 → 파일럿 → 기존 RADIUS·클라이언트 확인 → 감사 로그·복구 검증 순서에서 추출했다. 과거 검토 결과는 운영 환경에서 실행하지 않았음을 기록한다. [당시 작업 결과](../../.agent-work/legacy/softether-ssl-vpn-runbook-20261027/source/result.md)

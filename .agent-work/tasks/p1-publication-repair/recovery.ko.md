# P1 게시 검사 복구

실제 게시 단계에서 기존 CRLF 파일의 원본 Git 객체와 새로 정규화한 작업 파일의 객체를 비교해 오탐이 발생했습니다. 시험한 내용과 커밋 내용이 같은 파일도 차단되었습니다.

의존 파일과 작업 산출물·증거 사본에 대해, 검토 당시 원본 SHA256과 커밋 원본이 같거나, 기존 Git 정규화 비교가 정확히 일치하는 경우를 구분합니다. 파일 종류·모드·경로와 나머지 제출·게시 검사는 유지합니다. 실제 내용 변경과 모드 변경은 계속 차단합니다.

기존 대기 커밋 `7821707`과 제출 기록은 보존합니다. 마지막 게시 커밋 `01fbaaf`에서 새 복구 작업을 만들어 수정·시험·독립 평가를 수행하고, 그 작업을 실제 P1 검사로 제출·게시합니다. Git 설정 변경이나 직접 푸시로 검사를 우회하지 않습니다.

복구 게시 후 기존 작업 폴더가 깨끗하고 알려진 대기 커밋에 있는지 확인합니다. 대기 커밋을 `codex/p1-activation-blocked` 브랜치에 보존한 상태에서 기존 main을 검증된 원격 커밋으로 전환합니다. 사용자 변경이나 과거 제출 증거는 덮어쓰지 않습니다.

실제 결과와 검증 근거는 이 작업의 결과 보고서·evidence에 저장합니다. 커밋 후 게시 영수증은 별도 로컬 기록입니다. 이 기능은 로컬 CLI 경로의 검사이며 직접 Git 우회 차단과 호스트 격리는 후속 범위입니다.

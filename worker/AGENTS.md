# 작업 역할 관리 폴더

이 폴더는 GitHub `DurianCream/private` 단일 저장소 안에서 Codex 역할 지침·스킬의 관리 원본을 보관한다. 실제 업무를 infra_worker로 배정받았을 때 역할 정의와 상세 스킬을 적용한다. 이 역할 폴더의 유지보수 요청은 사용자 요청 범위에 따라 수행한다.

- 역할 정의: [TOML](codex/infra_worker.toml)
- 상세 절차: [스킬](skills/infra-work/SKILL.md)
- 전체 흐름·수정 방법: [조율자 문서](../conductor/README.md)

이 정의는 수정 가능한 프로토타입이다. 전역 회사 정보 보호·한국어 보고·실행 승인 지침과 플랫폼 권한은 그대로 따른다.

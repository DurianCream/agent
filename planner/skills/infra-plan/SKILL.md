# 계획 역할

조율자가 전달한 목표와 변경·관찰 범위를 기준으로 계획을 작성한다. 실제 상태를 확인할 접근 수단이 없으면 필요한 증거를 명시하고, 지원되는 부분의 계획을 완성한다.

- 공식 자료의 적용 버전과 현재 확보한 로컬 증거를 구분한다. 공개 검색에는 제품명·공개 버전·민감정보를 제거한 오류만 사용한다.
- 각 작업의 범위, 선행 작업, 산출물, 완료 기준을 정한다. 병렬화는 입력 의존 관계와 공유 파일·실행 환경을 함께 고려한다.
- 검사 목록은 해당 목표를 증명하는 데 필요한 항목으로 정한다. 설명·문서 작업에 불필요한 실행 테스트를 만들지 않는다.
- 추가 정보가 필요하거나 실제 운영 변경 승인이 필요한 단계를 표시한다. 계획 작성이 그 실행을 승인하는 것은 아니다.
- 서버 장애·자원 문제에는 같은 레포의 `../infra-server-triage/SKILL.md`, 연결 문제에는 `../infra-network-diagnosis/SKILL.md`를 읽는다. 일반 개념 설명에는 해당 진단 스킬을 불러오지 않는다.
- 계획을 조율자에게 반환한다. 하위 에이전트 호출과 계획 파일 저장은 조율자가 맡는다.

기록 형식은 [단계 전달 프로토콜](/home/dhyun/ai-agent-repos/acceptance-gate/skills/infra-evidence-gate/references/protocol.md)을 따른다. `plan.json`에는 최소 한 작업, 전체 완료 기준 ID, 필요한 검사 ID를 포함한다.

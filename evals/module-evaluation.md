# Module Evaluation Criteria

Before registration, use doctor to check manifests and referenced files, duplicate IDs, versions, dependencies, and cycles.

Before production use, evaluate actual outputs for representative requests, requests that must not activate the role, handling of failed/unexecuted checks, regressions, workspace/tool scope, and time/cost. Preserve actual commands and results as evidence files.

All provided role definitions remain experimental. Static structure and local CLI tests do not establish passing behavioral evaluation of specialist agents. Submit evaluation outcomes through the common result contract.
